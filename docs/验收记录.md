## 十、已知边界

- 跌倒检测为宽高比规则模拟
- 无专用烟火模型时使用 HSV 颜色规则
- 不实现真实人脸识别
- 数字孪生为二维/伪三维演示
- 单机 SQLite 不面向生产高并发
- 摄像头是否可用取决于客户机权限、驱动和占用状态
- 首次使用在线 YOLO 权重时可能需要网络；离线失败会自动降级

## 十一、验收结论

当前版本满足课程设计和创新项目答辩演示要求：可登录、可运行、可显示视频或模拟画面、可产生并保存告警、可进行门禁和传感器模拟、可展示地图与大屏，并具备可替换后端的接口预留。未发现阻止启动或核心演示流程的已知问题。
