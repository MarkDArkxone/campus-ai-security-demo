# Windows 运行说明

## 一、运行环境

- Windows 10/11
- Python 3.11 或更高版本
- PyCharm（可选）
- 建议内存 8 GB 以上
- 摄像头、YOLO 权重和真实硬件均不是启动系统的必要条件

安装 Python 时请勾选 **Add Python to PATH**。

## 二、最快启动方式

### 方式 A：批处理

1. 双击 `install.bat` 安装依赖。
2. 双击 `start.bat` 启动项目。
3. 查看命令窗口中的实际访问地址。
4. 浏览器打开默认地址 `http://127.0.0.1:8000`。

批处理执行结束或发生错误时会保留窗口，便于查看提示。

### 方式 B：命令行

```powershell
cd campus_ai_security_demo
python -m pip install -r requirements.txt
python run.py
```

### 方式 C：虚拟环境

```powershell
cd campus_ai_security_demo
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python run.py
```

如果 PowerShell 禁止激活脚本，可直接使用：

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

1. 登录后进入首页。
2. 点击“一键初始化演示数据”。
3. 进入 `/dashboard` 查看整体态势。

## 六、摄像头与本地视频

默认配置位于 `app/config.py`：

```python
VIDEO_SOURCE = 0
```

- `0`：默认摄像头
- `1`：第二个摄像头
- 本地视频：可设置为 `sample_videos/test.mp4`

也可以通过 `POST /api/config` 更新运行配置。摄像头打开失败时系统自动切换模拟画面，不会阻止页面启动。

## 七、YOLO 与烟火模型

默认人员模型：

```python
MODEL_NAME = "yolov8n.pt"
```

首次运行时 Ultralytics 可能尝试下载权重。如果客户机无法联网或模型加载失败，系统自动使用 mock 人员框。

烟火识别配置：

```python
FIRE_MODEL_PATH = ""
ENABLE_FIRE_DETECTION = True
FIRE_CONF_THRESHOLD = 0.4
```

`FIRE_MODEL_PATH` 为空或文件不存在时，系统使用 OpenCV HSV 颜色规则进行 Demo 级识别。

## 八、模拟硬件

- 视频：自动生成校园背景与移动人员
- 门禁：在 `/access` 选择人员和设备后模拟入校/出校
- 访客：在 `/visitors` 创建并审核预约
- 传感器：在 `/sensors` 启动三秒一次的模拟数据
- 异常：可手动触发烟雾、温度和电流超限
- 地图：使用 CSS 绘制，不需要额外图片

## 九、连接独立后端

系统默认使用同源 FastAPI 后端。若另一位同学提供独立后端，可在启动前设置：

```powershell
$env:CAMPUS_API_BASE_URL = "http://127.0.0.1:9000"
$env:CAMPUS_WS_BASE_URL = "ws://127.0.0.1:9000"
$env:CAMPUS_CORS_ORIGINS = "http://127.0.0.1:8000"
python run.py
```

前端通过 `app/static/js/api-client.js` 自动拼接 REST、WebSocket、静态资源和视频流地址。完整契约见 `docs/后端接入手册.md`。

## 十一、常见问题

### 1. `python` 不是命令

重新安装 Python 3.11+ 并勾选 Add Python to PATH，或在 PyCharm 中配置正确解释器。

### 2. 依赖安装慢或失败

PyTorch 和 Ultralytics 体积较大，请保持网络稳定。系统运行必须依赖基础包，但 YOLO 权重加载失败后可进入 mock 模式。

### 3. 登录失败

确认账号是 `admin / <CAMPUS_ADMIN_PASSWORD>`。若数据库来自旧版本，先备份 `data/campus_security.db`，再检查默认管理员是否存在。

### 4. 摄像头打不开

关闭占用摄像头的软件，检查 Windows 隐私权限。即使仍不可用，监控页也会显示模拟画面。

### 5. 端口被占用

`run.py` 会自动尝试相邻可用端口，请以终端打印的地址为准。

### 6. 页面显示 403

当前账号角色没有权限。管理和完整演示请使用 admin 登录。

### 7. 页面没有实时告警

检查浏览器控制台、`/api/health` 和 `/ws/alarms`。前后端分离时还要确认 `CAMPUS_WS_BASE_URL`、CORS 和代理设置。

### 8. 智能分析显示“—”

这表示对应高级指标尚无真实后端数据，不是页面故障。系统不会用随机值伪造分析结果。

### 9. 截图打不开

确认文件存在于 `app/static/snapshots/`，并检查后端返回的 `snapshot_path`。业务模拟告警没有视频帧时可能不带截图。

### 10. 数据需要重置

先停止程序并备份 `data/campus_security.db`。删除数据库后再次启动会自动建表和初始化基础数据；该操作会清空历史记录。

## 十二、停止系统

在运行窗口按 `Ctrl+C`。视频服务会停止并释放摄像头资源。

## 十三、Demo 限制

- 跌倒检测为边界框比例规则
- HSV 烟火检测可能误报或漏报
- 不实现真实人脸识别
- 地图与数字孪生为二维演示
- SQLite 仅适合单机课程项目
