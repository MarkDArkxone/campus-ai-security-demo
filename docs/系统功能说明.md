# 系统功能说明

> 项目名称：基于深度学习的校园智能安防系统 Demo  
> 定位：课程设计、创新项目申报和答辩演示用可运行 MVP

## 一、功能总览

系统将视频 AI、电子围栏、烟火检测、告警、门禁、访客、传感器、校园地图和态势大屏整合在同一套 FastAPI 应用中。没有摄像头、模型或真实硬件时，系统仍可通过模拟模式完成完整演示。

## 二、用户与权限

| 角色 | 主要权限 |
|---|---|
| admin | 所有页面、业务数据、系统配置和用户管理 |
| security | 监控、事件、门禁、传感器、地图和大屏 |
| teacher | 部分事件、访客、地图和大屏 |
| viewer | 大屏、地图和系统状态 |

- 默认管理员：`admin / <CAMPUS_ADMIN_PASSWORD>`
- 未登录访问后台页面自动跳转到 `/login`
- 无权限访问显示 403 页面
- 密码只保存哈希值

## 三、页面说明

| 页面 | 地址 | 说明 |
|---|---|---|
| 首页 | `/` | 系统状态、演示流程、一键数据初始化和告警触发 |
| 数字孪生大屏 | `/dashboard` | 核心指标、校园地图、最新告警、类型统计和趋势 |
| 视频监控 | `/monitor` | MJPEG 实时画面、检测状态、实时告警和风险指标 |
| 智能分析 | `/analysis` | 风险证据、趋势和高级模型预留状态 |

| 告警兼容地址 | `/alarms` | 保留旧地址，指向事件中心能力 |
| 设备管理 | `/devices` | 摄像头、门禁、传感器统一在线状态 |
| 门禁管理 | `/access` | 人员、设备、模拟通行和出入记录 |

## 四、视频智能检测

- 支持默认摄像头 `VIDEO_SOURCE = 0`
- 支持本地视频文件
- YOLOv8 `person` 检测
- 模型不可用时自动生成 mock 人员框
- 摄像头不可用时自动生成模拟校园画面
- 绘制人员框、置信度、电子围栏、人数和运行状态
- 通过 `/video_feed` 输出 MJPEG
- 支持启动和停止，停止时释放视频资源

### 告警规则

- `fence_intrusion`：人员中心点进入电子围栏
- `crowd_gathering`：同帧人数达到阈值
- `fall_suspected`：宽高比超限并持续多帧
- `fire_detected`：检测到火焰
- `smoke_detected`：检测到烟雾
- `fire_risk_high`：视频烟火与烟雾传感器出现复合风险

## 五、告警中心

- 所有告警写入 SQLite 的 `AlarmEvent`
- 视频告警保存当前帧到 `app/static/snapshots/`
- 同类告警使用冷却时间防止刷屏
- 支持按类型、等级、状态和时间查看
- 支持查看详情、截图和处置状态
- 支持导出列表
- 新告警通过 WebSocket 实时推送

## 六、门禁与访客

### 人员管理

- 新增人员
- 查看姓名、身份、学工号、部门和状态
- 修改正常、禁用和黑名单状态

### 门禁设备

- 展示设备名称、位置、类型和在线状态
- 默认初始化校园入口和宿舍门禁设备

### 模拟通行

- 选择人员、设备、入校/出校和认证方式
- 正常人员记录为 `allowed`
- 黑名单或禁用人员记录为 `denied`
- 黑名单通行同步产生 `access_denied` 告警

### 访客管理

- 新增访客预约
- 审核通过或拒绝
- 查看预约时间、来访原因、被访人和状态
- 支持模拟访客入校

## 七、传感器接入

支持以下模拟设备：

- 烟雾 `smoke`
- 温度 `temperature`
- 电流 `current`
- 电压 `voltage`
- 湿度 `humidity`

后台模拟任务每 3 秒生成数据，并写入 `SensorData`。页面可查看最新值、设备阈值、状态和历史曲线。

超限告警：

- 烟雾：`smoke_warning`
- 温度：`temperature_warning`
- 电流：`electricity_warning`

系统支持手动触发异常，便于现场演示。

## 八、校园地图

- 使用 CSS 绘制简化校园平面图，无需地图图片或第三方地图框架
- 显示摄像头、门禁、传感器和告警区域
- 绿色表示正常，黄色表示警告，红色表示告警，灰色表示离线
- 点击点位显示名称、类型、位置、状态和最近告警
- 新告警到达时关联点位变红或闪烁

## 九、数字孪生态势大屏

- 今日告警总数
- 高危告警数量
- 在线和离线设备数量
- 当前监控人数
- 最新告警自动滚动
- 高危告警红色强调
- 校园点位态势
- 告警类型统计
- 近 24 小时真实告警趋势
- 当前时间实时刷新
- 每 5 秒刷新统计，并监听 WebSocket

## 十、设备、分析与设置

### 设备管理

统一查看视频、门禁和传感器设备状态。设备汇总接口预留给独立后端和多设备扩展。

### 智能分析

展示系统已有的风险证据和趋势。没有后端数据的高级 DS 指标返回 `null`，页面显示“—”或“暂无数据”，避免将占位值误认为检测结论。

### 系统设置

展示健康状态、视频运行状态、模拟状态、API 契约版本和连接信息。阈值更新继续使用现有配置接口。

## 十一、后端接口能力

- REST：业务查询、创建、更新、删除和模拟操作
- WebSocket：`/ws/alarms` 实时告警
- MJPEG：`/video_feed` 视频流
- OpenAPI：`/docs`
- 集成清单：`/api/integration/manifest`
- 证据接口：`/api/evidence/current`、`/api/evidence/trends`
- 设备汇总：`/api/devices/summary`
- 系统诊断：`/api/system/diagnostics`

完整字段和接入步骤见 `docs/后端接入手册.md`。

## 十二、模拟模式

| 缺失条件 | 系统处理 |
|---|---|
| 无摄像头 | 生成模拟校园背景 |
| 无人员模型 | 生成移动的 mock 人员框 |
| 无烟火模型 | 使用 HSV 颜色规则 |
| 无门禁硬件 | 使用页面按钮模拟通行 |
| 无传感器硬件 | 后台每 3 秒生成模拟数据 |
| 无地图图片 | 使用 CSS 校园平面图 |

## 十三、使用边界

- 本项目是教学 Demo，不用于真实校园生产值守。
- 跌倒识别是规则模拟，不是医学判断。
- HSV 烟火识别可能误报或漏报。
- 不实现真实人脸识别。
- 二维地图不等同于真正三维数字孪生。
- SQLite 适合单机演示，不适合高并发生产部署。
