# 答辩演示流程

> 适用版本：Campus AI Security Demo 2.0  
> 建议时长：8～12 分钟  
> 默认账号：`admin / <CAMPUS_ADMIN_PASSWORD>`

## 一、演示前检查

1. 在项目目录执行 `python run.py`，或双击 `start.bat`。
2. 终端出现访问地址后，用浏览器打开该地址。默认是 `http://127.0.0.1:8000`；端口被占用时程序会自动尝试相邻端口。
3. 使用 `admin / <CAMPUS_ADMIN_PASSWORD>` 登录。
4. 首页点击“一键初始化演示数据”，确保人员、设备、传感器、地图点位、访客和历史告警齐全。
5. 提前确认 `/monitor` 能显示真实摄像头、本地视频或模拟校园画面中的任意一种。

## 二、推荐演示顺序

### 1. 登录与权限

- 打开登录页，说明系统使用 Session 登录和角色权限控制。
- 登录后展示统一导航栏。
- 说明 `admin`、`security`、`teacher`、`viewer` 四类角色的访问范围不同。

### 2. 数字孪生态势大屏

- 进入 `/dashboard`。
- 展示今日告警、高危告警、在线/离线设备、当前监控人数。
- 展示校园地图、最新告警、告警类型统计和近 24 小时趋势。
- 指出当前时间实时刷新，最新告警会自动滚动，高危告警使用醒目的红色状态。

### 3. 视频智能监控

- 进入 `/monitor`，点击“启动检测”。
- 说明系统优先使用 YOLOv8 检测人员；模型不可用时自动使用 mock 检测，摄像头不可用时自动生成模拟画面。
- 展示人员框、电子围栏、人数、运行状态以及烟火识别提示。
- 说明疑似跌倒仅使用检测框宽高比和连续帧规则，不代表医学判断。

### 4. 快速触发告警

回到首页，依次使用演示按钮：

1. 触发电子围栏告警。
2. 触发人员聚集告警。
3. 触发疑似跌倒告警。
4. 触发烟雾异常告警。
5. 触发温度异常告警。
6. 触发黑名单通行告警。

每次触发后说明：告警会写入 SQLite，并通过 WebSocket 推送到监控页、地图页和大屏。

### 5. 事件中心

- 进入 `/events`，也可使用兼容地址 `/alarms`。
- 展示事件筛选、详情、状态、人数、置信度和截图链接。
- 演示确认/处置事件以及导出功能。
- 视频告警通常带截图；纯业务模拟告警可能没有截图，这是正常情况。

### 6. 智能分析

- 进入 `/analysis`。
- 展示风险指标、趋势和分析区。
- 强调系统只展示后端已提供的真实数据；尚未接入的 DS/高级模型指标显示“—”或“暂无数据”，不会伪造结果。

### 7. 校园地图联动

- 进入 `/map`。
- 点击摄像头、门禁、传感器和告警区域点位查看详情。
- 再触发一条告警，展示对应点位变红或闪烁。

### 8. 门禁业务闭环

- 进入 `/access`。
- 选择正常人员模拟入校，结果应为 `allowed`。
- 选择黑名单人员模拟入校，结果应为 `denied`，并产生 `access_denied` 告警。
- 在记录区展示人员、设备、认证方式和通行结果。

### 9. 传感器模拟

- 进入 `/sensors`，启动模拟数据。
- 展示烟雾、温度、电流、电压、湿度的最新值和历史曲线。
- 手动触发烟雾、温度或电流异常，展示阈值告警和实时推送。

### 10. 设备与系统设置

- 进入 `/devices` 查看摄像头、门禁和传感器的统一状态。
- 进入 `/settings` 查看运行配置、健康状态和后端连接信息。
- 打开 `/api/integration/manifest`，说明前后端已经通过版本化契约解耦，可由另一位同学替换后端实现。

## 三、备用演示方案

遇到现场设备不可用时按以下方式继续：

- 摄像头不可用：系统自动显示模拟校园画面。
- YOLO 模型加载失败：系统自动生成 mock 人员框。
- 无烟火模型：使用 OpenCV HSV 颜色规则。
- 无门禁和传感器硬件：使用页面按钮与后台模拟任务。
- WebSocket 暂时断开：页面会保留 REST 数据，并在连接恢复后继续接收事件。
- 默认端口被占用：查看终端打印的实际访问地址。

## 四、答辩说明重点

- 本项目定位是可运行的校园安防 MVP，不是商业级平台。
- 数据库、告警、实时推送、门禁和传感器形成了完整业务闭环。
- 所有硬件能力都有模拟模式，保证普通 Windows 电脑可独立演示。
- 不做人脸识别，降低隐私和合规风险。
- 不声称实现真正三维孪生或医学级跌倒识别。

## 五、演示收尾

1. 打开 `/dashboard`，确认统计数据已随演示告警更新。
2. 打开 `/events`，确认刚产生的告警已入库。
3. 点击“停止检测”，确认摄像头资源能够释放。
4. 总结系统的可运行性、可扩展接口和后续模型升级方向。
